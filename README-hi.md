# बाहरी कार्य संदर्भ (dsh-external-task-context)

DSH Web के दाएँ साइडबार में बाहरी सबएजेंट कार्यों (Claude Code, Codex, ACP) का प्रतिनिधित्व संदर्भ, प्रॉम्प्ट, रनटाइम विकल्प और लौटाया गया परिणाम देखें।

## Features and location

- **सत्र हेडर बटन**: जब वर्तमान सत्र में बाहरी कार्य दर्ज हों, तो हेडर में «बाहरी कार्य N» बटन दिखता है; क्लिक करने पर प्लगइन का पेज दाएँ साइडबार में खुलता है (जगह होने पर नए पैन में)।
- **साइडबार पैनल**: बाईं ओर कार्यों की सूची (लेबल या छोटा id, स्थिति, आरंभ समय), दाईं ओर चयनित कार्य का विवरण। डिफ़ॉल्ट रूप से नवीनतम कार्य चुना जाता है; स्पष्ट चयन तब तक बना रहता है जब तक कार्य मौजूद है।
- **विवरण**: स्थिति, आरंभ/समाप्ति समय, टूल नाम, प्रतिनिधित्व प्रॉम्प्ट, कार्य निर्देशिका, प्रदाता/मॉडल/रीज़निंग एफ़र्ट/प्रीसेट, लौटाया गया पाठ और समापन सारांश। 64 KiB से लंबा पाठ स्थानीयकृत सूचना के साथ काटा जाता है।

## Data sources

दिखाया गया सब कुछ पहले से **मूल सत्र लॉग** में दर्ज है; प्लगइन कोई नया सत्र इवेंट नहीं जोड़ता और मॉडल-दृश्य व्यवहार नहीं बदलता:

1. `tool/call`: प्रतिनिधित्व टूल के आर्ग्युमेंट JSON में `description` कैटलॉग लेबल और `prompt` कार्य है; वैकल्पिक `cwd`, `provider`, `model`, `reasoning_effort`, `agent_preset` रनटाइम संदर्भ हैं।
2. `subagent/catalog` v2: बाहरी चाइल्ड की स्थिर id स्थापित करता है।
3. बाद में आने वाला `user/message` जिसमें `source.kind === 'subagent-settled'` है: समापन सारांश, चाइल्ड का अंतिम पाठ और वैकल्पिक निदान।

होस्ट इन इवेंट्स को `externalTaskContexts` प्रोजेक्शन में मोड़ता है; क्लाइंट केवल वही प्रोजेक्शन पढ़ता है।

## Known limitations

बाहरी प्रदाता अलग प्रक्रिया में चलते हैं; DSH उनके आंतरिक चरण या टूल कॉल दर्ज नहीं करता, और बाहरी चाइल्ड का स्थानीय सत्र या ट्रांसक्रिप्ट नहीं होता। इसलिए यह प्लगइन केवल प्रतिनिधित्व संदर्भ और लौटाया गया परिणाम दिखा सकता है — बाहरी एजेंट का निजी संदर्भ, आंतरिक तर्क या पूरा टूल कॉल क्रम नहीं। DSH `0.2.1-rc.2` में Claude Code प्रदाता `persistSession: false` का उपयोग करता है।

साथ ही, लेबल मिलान केवल तब होता है जब वह असंदिग्ध हो; केवल नवीनतम 20 बिना जोड़े प्रतिनिधित्व रखे जाते हैं; और fork से विरासत में मिले इवेंट (`seq < inheritedEventCount`) वर्तमान सत्र को नहीं दिए जाते।

## Installation

DSH `0.2.2-alpha.2` या नया और Node `^22.19 || >=24` आवश्यक है।

### npm से

```sh
dsh plugin add @lifenrir/dsh-external-task-context
```

### git से

```sh
dsh plugin add git+https://github.com/LiFenrir/dsh-external-task-context.git
```

### स्थानीय निर्देशिका से

```sh
git clone https://github.com/LiFenrir/dsh-external-task-context.git
cd dsh-external-task-context
pnpm install
pnpm run build
dsh plugin add /absolute/path/to/dsh-external-task-context
```

स्थानीय बिल्ड `lib/index.js` (होस्ट) और `lib/client.js` (वेब क्लाइंट) बनाता है।

फिर उस प्रोफ़ाइल में बंडल सक्षम करें। होस्ट प्रोजेक्शन और क्लाइंट बंडल लोड होने के लिए ऐप को पुनः आरंभ करें या सत्र फिर से खोलें।

## Usage

1. मॉडल से बाहरी सबएजेंट टूल द्वारा कार्य सौंपने को कहें।
2. प्रतिनिधित्व दिखने पर हेडर का «बाहरी कार्य» बटन दबाएँ।
3. बाईं ओर कार्य चुनकर उसका प्रॉम्प्ट, संदर्भ और परिणाम देखें।

## Privacy

प्रोजेक्शन सत्र प्रोजेक्शन कैश के साथ सहेजा जाता है, इसलिए प्रॉम्प्ट और परिणाम सत्र लॉग के बाहर दूसरी बार संग्रहीत होते हैं। साझा वातावरण में या सत्र निर्यात करते समय इन्हें उसी संवेदनशीलता से संभालें।
